# 大富翁遊戲 (Monopoly Game)

## 專案介紹
本專案是一個基於 Python 的大富翁遊戲，玩家可以擲骰子移動並進行資產管理，分析不同的遊戲規則並執行20萬次，分析不同遊戲規則下，玩家出發順序是否會影響勝率。
- 方法1 : 土地金額都為200
- 方法2 : 土地金額第一排100 第二排150 第三排200 第四排250
- 方法3 : 土地初始金額，每持有一筆土地，土地的價值多10%
- 結合1~3
- 結合1~3並創建機會格 : 採到機會格會觸發隨機事件，例如搶奪罪多錢的玩家，直接破產等

## 功能特色
- **玩家管理**: 創建多個玩家，每位玩家有初始金額與位置。
- **地圖設計**: 使用 10x10 格的棋盤，每位玩家按照規則移動。
- **擲骰機制**: 透過隨機數模擬擲骰結果，決定玩家行動。
- **破產判斷**: 若玩家資金低於 0，則破產退出遊戲。

## 遊戲規則
- 每位玩家起始時擁有 $1000。
- 擲骰後，依照點數決定前進步數。
- 若玩家資產歸零，則破產退出。
- 先存活的玩家為贏家。

## 結果分析
- 方法1中獲勝次數為[59716, 53088, 46436, 40760] 先出發的勝率越高
- 方法2中獲勝次數為[52970, 51206, 48858, 46966] 先出發的勝率越高，但勝率差距有減少趨勢
- 方法3中獲勝次數為[77624, 52942, 39044, 30390]，勝率差距擴大
- 方法1~3中獲勝次數為[51336, 50278, 49477, 48909]，勝率較為平均
- 方法1~3加機會格獲勝次數為[44181, 43062, 40888, 71869]，最後出發的優勢增加

## 結論
在大富翁遊戲中，越早出發買到土地的機會越高，越容易獲得勝利，可以藉由改變土地價格，越後面土地越貴的方式來平衡勝率
也可以創建機會格來改變勝率的排行，增加後出發玩家的勝率
